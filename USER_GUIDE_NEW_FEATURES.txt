KRAK Editor - New Features User Guide
====================================

This guide explains how to use the new features in the updated KRAK Editor.

GETTING STARTED:
================

1. Start the KRAK Editor as usual:
   .\venv\Scripts\python.exe krak_editor_gui.py

2. Load a parquet file from the file list (same as before)

3. You will now see new sections in the interface

NEW FEATURES OVERVIEW:
=====================

1. SIGNAL PROCESSING PARAMETERS
-------------------------------

Location: Between the playback controls and the plot

What you'll see:
- Start Threshold: Slider (0.0 to 2.0)
- Stop Threshold: Slider (0.0 to 2.0)
- Hysteresis: Input field
- Extra Time: Input field
- Min Duration: Input field

How to use:
- Move the sliders to adjust threshold values
- The plot will update automatically when you change thresholds
- These settings affect how the signal is processed for trimming

2. CONFIGURATION LOADING
------------------------

Location: In the Signal Processing Parameters section

What you'll see:
- "Load Config:" dropdown menu
- "Refresh" button
- "Load Config" button
- Status showing current config

How to use:
- Click "Refresh" to see available configurations from server
- Select a configuration from the dropdown
- Click "Load Config" to apply the settings
- All sliders will update automatically with the loaded values

3. TRIMMED SIGNAL VISUALIZATION
------------------------------

Location: Plot area and Signal Processing Parameters

What you'll see:
- "Show Trimmed Signal" checkbox
- Orange highlighted regions on plots
- Threshold lines (green and red)
- Purple reference signal when trimmed view is active

How to use:
- Check "Show Trimmed Signal" to see processing visualization
- Orange areas show which parts will be kept after trimming
- Green line = Start Threshold, Red line = Stop Threshold
- Reference signal turns purple and shows DC offset compensation
- Uncheck to return to normal view

4. ENHANCED METADATA SEARCH
---------------------------

Location: Left panel metadata search

What's new:
- "Search Logic" radio buttons
- Better value matching

How to use:
- Select "AND (all must match)" for strict searching
- Select "OR (any can match)" for broader searching
- Value fields now find partial matches (not exact)
- Example: Searching "fast" will find "fast", "faster", "breakfast", etc.

STEP-BY-STEP WORKFLOW:
=====================

Basic Signal Processing:
1. Load a parquet file
2. Adjust threshold sliders while watching the plot
3. Check "Show Trimmed Signal" to see the effect
4. Fine-tune thresholds as needed

Using Server Configurations:
1. Click "Refresh" in the config section
2. Select a configuration from the dropdown
3. Click "Load Config"
4. All parameters will be set automatically
5. Optionally adjust individual parameters

Advanced Search:
1. Enter search criteria in Key/Value fields
2. Choose AND or OR logic
3. Use partial words in value fields
4. Click "Search" to find matching files

TIPS:
=====

- Threshold lines are always visible on the reference signal plot
- Orange highlighting only appears when "Show Trimmed Signal" is checked
- You can load different configs and compare results instantly
- Search is now more flexible - try partial words
- All changes are for visualization only - no files are modified

WHAT STAYS THE SAME:
===================

- File loading and browsing works exactly as before
- Metadata editing and saving unchanged
- Plot navigation and zooming unchanged
- All existing keyboard shortcuts work
- Cache refresh and index management unchanged

If you need help or encounter issues, contact technical support.
