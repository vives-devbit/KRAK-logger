# KRAK-logger
This is the software for logging KRAK sound and force recordings

## 🚀 Quick Setup (Multi-User Environment)

This project supports multiple users with different Python installations. Each user gets their own virtual environment.

### First Time Setup

```powershell
.\setup_venv.ps1
```

### Daily Use

```powershell
.\activate_venv.ps1
python krak_logger_gui.py
```
